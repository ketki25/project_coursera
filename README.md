A simple interest calculator project
# GitHub Final Project

## About
This project contains a simple interest calculator
written in Bash.

## Formula
Simple Interest = (P × R × T) / 100

Where:
- P = Principal amount
- R = Rate of interest
- T = Time in years

## Usage
Run the simple-interest.sh script using Bash.
